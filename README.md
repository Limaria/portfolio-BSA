## Описание

Портфолио основанно на проектах Школы 21 и университета

## Структура проекта

| Папка                       | Содержание                              |
| --------------------------- | --------------------------------------- |
| `AsIs_ToBe`                 | Модели процессов AS-IS и TO-BE          |
| `BPMN`                      | BPMN-диаграммы бизнес-процессов         |
| `Decomposition`             | Декомпозиция задачи                     |
| `Diagrams`                  | Прочие диаграммы (UML)                  |
| `Domains`                   | Описание предметных областей            |
| `FunctionalRequirements`    | Функциональные требования               |
| `NonfunctionalRequirements` | Нефункциональные требования             |
| `Objects_and_Roles`         | Объекты системы и роли пользователей    |
| `UseCase`                   | Варианты использования (Use Cases)      |
| `UserStory`                 | Пользовательские истории (User Stories) |
